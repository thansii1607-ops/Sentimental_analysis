# AI Sentiment Analyzer

AI Sentiment Analyzer is a simple web application that analyzes the sentiment of a given text using Artificial Intelligence.

## Description

This project uses a pre-trained Hugging Face Transformers model to identify whether the entered text is Positive or Negative. The application is developed using Python and Streamlit.

## Features

- Simple and easy-to-use interface
- Analyzes text sentiment
- Detects Positive and Negative sentiment
- Displays confidence score
- Uses Hugging Face Transformers

## Technologies Used

- Python
- Streamlit
- Hugging Face Transformers
- PyTorch


## Installation

Install the required libraries using:

python -m pip install -r requirements.txt

## Run the Application

Run the following command:

python -m streamlit run app.py

## How to Use

1. Open the Streamlit application.
2. Enter a sentence in the text box.
3. Click the "Analyze" button.
4. The application displays the sentiment.
5. The confidence score is also displayed.

## Requirements

streamlit
transformers
torch

## Conclusion

This project demonstrates how Artificial Intelligence and Natural Language Processing can be used to analyze the sentiment of text through a simple web application.
